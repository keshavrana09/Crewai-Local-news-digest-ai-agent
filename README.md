# CrewAI Local News Digest AI Agent

An AI-powered news digest project built with Python and CrewAI to explore agent-based research, information processing, and news summarization.

## About the Project

This project explores how AI agents can help automate the process of gathering news, extracting relevant information, and producing concise summaries. It demonstrates the use of agentic AI concepts to organize research tasks into a structured workflow.

## Objectives

- Explore multi-agent systems using CrewAI.
- Automate parts of the news research process.
- Generate concise, readable news summaries.
- Reduce the manual effort involved in reviewing multiple news sources.
- Learn how specialized AI agents can collaborate on a shared task.

## Tech Stack

- **Language:** Python
- **Agent Framework:** CrewAI
- **AI / LLMs:** The language model configured in the project
- **Other tools:** As configured in the project dependencies

## How It Works

1. Define the news research task.
2. Configure the agents and their responsibilities.
3. Gather and process relevant news information.
4. Summarize the findings into a digest.
5. Review the generated output.

*The exact workflow depends on the implementation in this repository.*

## Getting Started

Clone the repository:

```bash
git clone https://github.com/keshavrana09/Crewai-Local-news-digest-ai-agent.git
cd Crewai-Local-news-digest-ai-agent
```

Install dependencies according to the project's dependency file and configure any required API keys or environment variables before running the application.

**Security:** Never commit API keys, passwords, or `.env` files containing secrets.
